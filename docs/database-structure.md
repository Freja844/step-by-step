# Step by Step

Step by Step is a Danish prototype marketplace for dog owners and dog walkers. This MVP is a mobile-first concept demo built with Vite and vanilla JavaScript to keep the project lightweight and easy to run locally.

## Features included

- Landing page with hero, value proposition and CTA buttons
- Dog walker search with filter controls
- Dog listings for walkers
- Booking flow with status states and pricing preview
- In-app messaging UI tied to a booking
- Separate owner and walker dashboards
- Profile page with verification badges and prototype labeling
- Safety page with report/block actions
- Payment preview that clearly states it is a prototype
- Database design overview for users, profiles, dogs, availability, bookings, messages and reviews
- Demo data for Lisa, Minnie, Alex, Emma and Noah
- Responsive mobile-first design with bottom navigation on small screens

## Run locally

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open the local Vite URL in the browser.

## Prototype note

This is a free MVP prototype and intentionally does not include real payments, real identity verification, insurance, MitID, or production hosting.
